# 🔐 Система подтверждения входа в админку

## Как это работает

Каждый раз при входе в админ-панель генерируется **новый 6-значный код**, который:
- Действителен **10 минут**
- Можно использовать **только 1 раз**
- После подтверждения доступ к админке на **1 час**

## Настройка Telegram бота

### Шаг 1: Запустите бота

```bash
node bot.js
```

Вы увидите:
```
✅ Бот запущен: @your_bot_name
📋 Команды:
   /start — информация
   /link email — привязать email к Telegram
```

### Шаг 2: Привяжите ваш Telegram к email

1. Откройте Telegram
2. Найдите вашего бота (указан в консоли)
3. Отправьте команду: `/start`
4. Отправьте команду: `/link admin@imperia.com`

Бот ответит:
```
✅ Аккаунт успешно привязан!
📧 Email: admin@imperia.com
💬 Chat ID: 123456789

Теперь коды подтверждения будут приходить сюда.
```

### Шаг 3: Войдите в админку

1. Откройте `/admin` на сайте
2. Автоматически откроется `/admin/verify`
3. Код **придёт в Telegram** (и также в консоль сервера)
4. Введите код → доступ открыт на 1 час

## Доступные admin emails

По умолчанию доступ есть у:
- `admin@imperia.com`
- `founder@imperia.com`

Чтобы добавить новые, отредактируйте:
- `lib/adminAuth.js` — функция `isAdminEmail()`
- `bot.js` — массив `adminEmails` в функции `handleLink()`

## Запуск dev сервера

Для полной работы нужно запустить **2 процесса**:

**Терминал 1 — Next.js сервер:**
```bash
npm run dev
```

**Терминал 2 — Telegram бот:**
```bash
node bot.js
```

## Troubleshooting

### Бот не отправляет коды

**Проблема:** Коды только в консоли, не приходят в Telegram

**Решение:**
1. Убедитесь что `node bot.js` запущен
2. Проверьте что вы выполнили `/link your@email.com` в боте
3. Проверьте консоль бота — должно быть `Email ... привязан к chat_id ...`

### Код не принимается

**Проблема:** Пишет "Неверный или истёкший код"

**Причины:**
- Код истёк (10 минут прошло)
- Код уже использовался
- Email не совпадает с тем, для кого был сгенерирован

**Решение:**
- Нажмите "Отправить код повторно"
- Используйте новый код

### Нет прав администратора

**Проблема:** "У вас нет прав администратора"

**Решение:**
Добавьте ваш email в `lib/adminAuth.js`:
```js
export function isAdminEmail(email) {
  const adminEmails = [
    'admin@imperia.com',
    'founder@imperia.com',
    'your-email@example.com',  // ← добавьте сюда
  ]
  return adminEmails.includes(email.toLowerCase())
}
```

## Production рекомендации

В продакшене:

1. **Отключите devCode в ответе API:**
   Удалите строку из `app/api/admin/verify-code/route.js`:
   ```js
   devCode: process.env.NODE_ENV === 'development' ? generatedCode : undefined,
   ```

2. **Используйте Redis для кодов:**
   Замените `Map` в `lib/adminAuth.js` на Redis для работы с несколькими серверами

3. **Отправляйте коды через Email:**
   Интегрируйте SendGrid/Mailgun вместо Telegram (или вместе)

4. **Мониторинг:**
   Логируйте попытки входа, неверные коды, блокируйте после 5 попыток

5. **Запустите бота как service:**
   Используйте PM2 или systemd для автозапуска бота
