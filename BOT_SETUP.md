# Настройка Telegram бота для админ-кодов

## Что делает бот

Telegram бот отправляет одноразовые коды подтверждения администраторам для входа в админ-панель.

## Быстрый старт

### 1. Получите токен бота

1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Придумайте имя бота (например: `Imperia Pizza Admin`)
4. Придумайте username (например: `imperia_pizza_admin_bot`)
5. Скопируйте токен (формат: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)

### 2. Добавьте токен в .env.local

```bash
# imperia-next/.env.local
TELEGRAM_BOT_TOKEN=ваш_токен_здесь
```

Или используйте тестовый токен в коде (для dev).

### 3. Запустите бота

```bash
cd imperia-next
node bot.js
```

Вывод:
```
🤖 Telegram бот запускается...
✅ Бот запущен: @imperia_pizza_admin_bot
📋 Команды:
   /start — информация
   /link email — привязать email к Telegram
```

### 4. Привяжите свой Telegram к админ-email

1. Найдите вашего бота в Telegram
2. Отправьте команду: `/start`
3. Отправьте команду: `/link admin@imperia.com`

Бот ответит:
```
✅ Аккаунт успешно привязан!

📧 Email: admin@imperia.com
💬 Chat ID: 123456789

Теперь коды подтверждения будут приходить сюда.
```

### 5. Протестируйте вход

1. Откройте сайт: http://localhost:3000/login
2. Введите email: `admin@imperia.com`
3. Введите любой пароль
4. Нажмите "Войти"
5. Вас перенаправит на `/admin/verify`
6. **Код придет в Telegram** (если бот запущен)
7. **Код выведется в консоли** (всегда)
8. Введите 6-значный код
9. Доступ открыт на 1 час

## Работа без бота

Бот опционален! Если не запущен:

- Код всё равно генерируется
- Код выводится в консоль Next.js сервера
- В dev режиме код показывается в toast-уведомлении

## Команды бота

### `/start`
Показывает приветственное сообщение и инструкции

### `/link email@example.com`
Привязывает ваш Telegram к email администратора

**Разрешенные email:**
- `admin@imperia.com`
- `founder@imperia.com`

## Хранение кодов

Коды хранятся в памяти (Map) в `lib/adminAuth.js`:

```javascript
{
  code: '123456',
  email: 'admin@imperia.com',
  expires: Date.now() + 10 * 60 * 1000,
  used: false
}
```

- Срок действия: 10 минут
- Одноразовый (после использования удаляется)
- При перезапуске сервера все коды сбрасываются

## Безопасность

- Коды генерируются криптографически стойко (`crypto.randomInt`)
- 6 цифр = 1 миллион комбинаций
- Срок жизни 10 минут
- Одноразовые
- Middleware защищает `/admin/*` маршруты
- Cookie httpOnly (не доступна из JS)

## Production

В продакшене:

1. Уберите dev-режим (не показывать код в toast)
2. Настройте webhook вместо long polling
3. Используйте Redis для хранения кодов
4. Добавьте rate limiting (макс. 5 попыток/час)
5. Логируйте все попытки входа

## Troubleshooting

### Бот не отвечает
- Проверьте токен в `.env.local`
- Убедитесь что `node bot.js` запущен
- Проверьте интернет соединение

### Код не приходит в Telegram
- Проверьте что email привязан: `/link admin@imperia.com`
- Проверьте консоль бота на ошибки
- Код всегда выводится в консоль Next.js сервера

### "У этого email нет прав администратора"
- Добавьте email в список: `lib/adminAuth.js` → `ADMIN_EMAILS`
- Или используйте `admin@imperia.com` / `founder@imperia.com`

### Код не принимается
- Код действителен только 10 минут
- Код одноразовый (нельзя использовать дважды)
- Проверьте что вводите правильный email

## Альтернативы
