# Вход в админ-панель

## Система безопасности

Каждый раз при входе в админку генерируется **новый одноразовый код**. Старые коды автоматически удаляются.

## Как войти

### 1. Откройте страницу входа
```
http://localhost:3000/login
```

### 2. Войдите через Firebase Auth
- Email: `admin@imperia.com` или `founder@imperia.com`
- Пароль: любой (Firebase проверяет)
- Или войдите через Google

### 3. Автоматическая проверка
После успешного входа:
- Если email администратора → перенаправление на `/admin/verify`
- Если обычный пользователь → перенаправление на `/profile`

### 4. Получите код
На странице `/admin/verify`:
- Код **автоматически генерируется** при загрузке
- Код приходит:
  - ✅ В консоли сервера (всегда)
  - ✅ В toast уведомлении (dev режим)
  - ✅ В Telegram (если бот запущен и привязан)

### 5. Введите код
- 6 цифр
- Действителен 10 минут
- Одноразовый

### 6. Нужен новый код?
Нажмите кнопку **"Отправить код повторно"**:
- Старый код удаляется
- Генерируется новый код
- Вы получаете его теми же способами

## Важные детали

### Коды всегда меняются
```javascript
// При каждом запросе кода:
1. Удаляются все старые коды для этого email
2. Генерируется новый случайный код
3. Код действителен ровно 10 минут
4. После использования код удаляется
```

### Где смотреть код

#### В консоли Next.js сервера:
```

🔐 Код: 123456

```

#### В toast уведомлении (dev режим):
```

```

#### В Telegram (если настроен):
```
🔐 Код подтверждения для входа в админку

123456

⏱ Действителен 10 минут
🔒 Используйте только один раз
```

### Безопасность

- **10 минут** — время жизни кода
- **6 цифр** — 1 миллион возможных комбинаций
- **Одноразовый** — после использования удаляется
- **Уникальный** — каждый раз новый
- **Привязан к email** — нельзя использовать для другого email

### Cookie после входа

После успешной верификации устанавливаются cookies:
```javascript
adminVerified=true; path=/; max-age=3600  // 1 час
adminVerifiedAt=timestamp; path=/; max-age=3600
```

Доступ в админку действителен **1 час**, после чего нужно войти заново.

## Примеры использования

### Сценарий 1: Первый вход
1. Вхожу через `admin@imperia.com`
2. Перенаправляет на `/admin/verify`
3. Код автоматически сгенерирован: `123456`
4. Ввожу код → доступ открыт на 1 час

### Сценарий 2: Ошибся в коде
1. Ввел неправильный код → ошибка
2. Нажимаю "Отправить код повторно"
3. Получаю **новый код**: `789012`
4. Ввожу новый код → успешно

### Сценарий 3: Код истек
1. Прошло 10 минут после генерации
2. Пытаюсь ввести старый код → "Неверный или истёкший код"
3. Нажимаю "Отправить код повторно"
4. Получаю новый код и ввожу его

### Сценарий 4: Через час после входа
1. Прошёл 1 час после входа
2. Cookie истекла
3. Пытаюсь зайти на `/admin` → middleware перенаправляет на `/admin/verify`
4. Получаю новый код и подтверждаю доступ

## Разрешенные admin email

```javascript
// lib/adminAuth.js
const adminEmails = [
  'admin@imperia.com',
  'founder@imperia.com',
]
```

Чтобы добавить нового админа:
1. Откройте `lib/adminAuth.js`
2. Добавьте email в массив `adminEmails`
3. Сохраните файл

## Production рекомендации

1. **Используйте Redis** вместо Map для хранения кодов
2. **Rate limiting** — макс. 5 попыток в час
3. **Email уведомления** — отправляйте коды на email
4. **2FA приложения** — как альтернатива кодам
5. **Логирование** — сохраняйте все попытки входа
6. **IP whitelist** — ограничьте доступ по IP

## Troubleshooting

### Код не приходит
- ✅ Проверьте консоль сервера (код всегда там)
- ✅ В dev режиме смотрите toast уведомление
- ✅ Если настроен бот — проверьте Telegram

### "Неверный или истёкший код"
- Код действителен только 10 минут
- Запросите новый код кнопкой "Отправить код повторно"
- Каждый код одноразовый

### Перенаправляет на /login
- Middleware защищает `/admin/*`
- Сначала войдите через Firebase Auth
- Затем подтвердите доступ кодом

### Cookie не сохраняется
- Проверьте что браузер разрешает cookies
- В dev режиме должен работать localhost
- Cookies действительна 1 час
