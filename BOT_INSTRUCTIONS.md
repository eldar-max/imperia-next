# Инструкция по настройке Telegram бота

## Как это работает

1. **Администратор входит в систему** (admin@imperia.com или founder@imperia.com)
2. **Автоматически перенаправляется** на страницу `/admin/verify`
3. **Код генерируется автоматически** при загрузке страницы
4. **Код отправляется в Telegram бот** (если бот запущен и email привязан)

## Настройка

### Шаг 1: Запустите бота

```bash
cd imperia-next
node bot.js
```

Вы должны увидеть:
```
✅ Бот запущен: @my_flower_shop_2026_bot
📋 Команды:
   /start — информация
   /link email — привязать email к Telegram
```

### Шаг 2: Привяжите email к Telegram

1. Откройте Telegram
2. Найдите бота: `@my_flower_shop_2026_bot`
3. Отправьте команду: `/start`
4. Привяжите email: `/link admin@imperia.com`

Вы получите подтверждение:
```
✅ Аккаунт успешно привязан!
📧 Email: admin@imperia.com
💬 Chat ID: ваш_chat_id
```

### Шаг 3: Войдите в админку

1. Откройте `http://localhost:3000/login`
2. Войдите с email: `admin@imperia.com` (любой пароль 6+ символов)
3. Вас автоматически перенаправит на `/admin/verify`
4. **Код придет в Telegram автоматически!** 🎉

## Что проверить если код не приходит

1. **Бот запущен?**
   ```bash
   # Проверьте, что процесс bot.js работает
   ```

2. **Email привязан?**
   - Отправьте `/link admin@imperia.com` в бот
   - Проверьте что получили подтверждение

3. **Логи бота**
   - При входе в админку смотрите логи:
   ```
   [Bot] Попытка отправить код для admin@imperia.com
   [Bot] ✓ Chat ID найден: 123456789
   [Bot] ✅ Код 123456 отправлен
   ```

4. **Логи API**
   - В консоли Next.js должно быть:
   ```
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   📧 Новый код подтверждения для: admin@imperia.com
   🔐 Код: 123456
   ⏱️  Действителен 10 минут
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   ```

## Запуск обоих процессов одновременно

```bash
# Терминал 1: Next.js
cd imperia-next
npm run dev

# Терминал 2: Telegram бот
cd imperia-next
node bot.js
```

## Админские email

- `admin@imperia.com`
- `founder@imperia.com`

Оба должны быть привязаны через `/link` команду в боте.

## Troubleshooting

### Бот не отвечает
- Проверьте токен в `.env`: `TELEGRAM_BOT_TOKEN=8876197155:AAHHIYoEyFtk3qBS94ONfs2zfYa_lD8OoG8`
- Проверьте что бот не заблокирован BotFather

### Код не приходит в Telegram
- Отправьте `/link admin@imperia.com` еще раз
- Перезапустите бота
- Проверьте логи обоих процессов

### Код показывается только в консоли
- Это нормально, если бот не запущен или email не привязан
- Код всегда показывается в консоли сервера (для разработки)
